# Ross's second queueing conjecture

Research manuscript by Yitzchak Shmalo, Einstein Institute of Mathematics, The Hebrew University of Jerusalem.

This repository contains the paper and reproducible checks for finite-state counterexamples to the universal workload monotonicity assertion in L. Leskela, *Ross's second conjecture and supermodular stochastic ordering*, Queueing Systems 100 (2022), 213–215, Problem 1.

The manuscript, source, and exact-arithmetic verification are being assembled in the initial publication commits. Mathematical arguments and reproducibility checks are separate from external peer review and publication-priority verification. No journal acceptance is asserted.
